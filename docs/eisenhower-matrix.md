# FreshmanFit - Eisenhower Matrix

## Do - MVP

- Accept and validate the user's graduation year and field of interest.
- Load internship listings from a prepared CSV file.
- Filter internships by both graduation year and field.
- Display matching internships with company names and application
  links, or a message if no matches are found.

## Schedule - V2.0+

- Save selected internships to a favorites list.
- Sort matching internships by application deadline.
- Add filters for location and remote work.
- Export search results to a file.

## Delegate - Use Existing Tools

- Use Java's Scanner for terminal input.
- Use BufferedReader and FileReader for reading the CSV file.
- Use built-in String methods to remove extra spaces and compare
  text without case sensitivity.

## Delete - Out of Scope

- Automatically scrape internship listings from multiple websites.
- Build a mobile app or web interface.
- Use AI to analyze resumes and recommend internships.
- Automatically submit applications on the user's behalf.
